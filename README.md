# A.T Microgreens Complete Website

This folder is the complete replacement website source built from the accepted A.T Microgreens visual mockups.

## Pages
- Home
- Shop
- About
- How We Grow
- Gallery
- Wholesale
- FAQ
- Contact
- Basket
- Checkout (Coming Soon)

## Store behaviour
- 65 products and microgreen mixes
- All products default to Not in Stock
- Development stock controls can switch each product ON/OFF in the current browser
- Search and category filtering
- Quantity controls
- Add/remove basket items
- Basket persists using browser localStorage
- Checkout is deliberately disabled

## Alex approval placeholders
The logo/brand, company story, contact details, address, pack sizes, prices, delivery area, food-safety statements, sustainability claims and payment provider are intentionally not invented.

## Google Sites note
The connected Google Drive tools cannot directly edit or publish Google Sites. The existing public site was therefore left intact. This package is the replacement source ready for a Sites-capable editor or another hosting surface.
